# MobileAutomationFramework

Framework de automatización móvil desarrollado con **Java, Gradle, Appium, Cucumber, JUnit y BrowserStack**.

## 🎯 Objetivo

Crear una base de automatización que permita ejecutar pruebas sobre aplicaciones Android de forma local y también mediante BrowserStack.

## 🛠️ Tecnologías utilizadas

- Java
- Gradle
- Appium
- UiAutomator2
- Cucumber
- JUnit
- BrowserStack
- Git / GitHub
- IntelliJ IDEA

## 📱 Ejecución local Android

Para ejecutar las pruebas localmente:

1. Iniciar el emulador Android desde Android Studio.
2. Iniciar Appium:

```text
appium
